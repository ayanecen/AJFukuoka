# WordPress 追加 CSS

AJ福岡サイトで WordPress 管理画面の **外観 → カスタマイズ → 追加 CSS** に設定している内容を記録します。

WordPress の「追加 CSS」はデータベース側に保存され、Git 管理されているテーマファイルには含まれません。サイト移行・再構築・設定消失時に再現できるよう、このファイルに記録します。

## 固定ページのページタイトルを読みやすくする

### 背景

固定ページ上部のページタイトル（`.page-header__title`）が白文字で表示されており、白を基調とした梅の背景画像上では文字が背景に埋もれて読みにくくなっていました。

対象例:

- https://ajfukuoka.com/%e3%83%96%e3%83%ab%e3%83%99%e3%81%a8%e3%81%af/
- 「忘れ物コーナー」など同じページヘッダーを利用する固定ページ

### 適用 CSS

```css
/* 固定ページ上部のタイトル */
.page-header__title {
    display: inline-block;
    color: #222 !important;
    background: rgba(255, 255, 255, 0.5);
    padding: 0.25em 0.6em;
    text-shadow: none;
    font-size: 42px;
}

/* スマートフォン */
@media (max-width: 767px) {
    .page-header__title {
        font-size: 36px;
    }
}
```

### ねらい

- 文字色を `#222` にして視認性を確保
- 背景に白 50% 透過を敷き、背景画像の明暗に左右されにくくする
- デスクトップは 42px、スマートフォンは 36px としてタイトルを強調
- 親テーマ Habakiri のファイルは直接変更しない
